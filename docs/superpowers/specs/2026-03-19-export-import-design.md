# 导出/导入功能设计

**日期**: 2026-03-19
**状态**: 已批准

---

## 概述

为快捷链接添加导出和导入功能，支持 JSON 文件下载和剪贴板复制/粘贴。

---

## 新增元素

### 设置按钮
- 位置：右下角，主题切换按钮左侧（30px 间隔）
- 样式：与主题按钮一致（圆形 48px、柔和阴影、hover 缩放）
- 图标：齿轮 SVG

### 设置弹窗
- 圆角 24px
- 标题："设置"
- 包含：导出按钮、导入按钮

---

## 数据格式

```json
{
  "version": 1,
  "links": [
    {
      "name": "哔哩哔哩",
      "url": "https://bilibili.com",
      "iconMode": "favicon",
      "icon": ""
    }
  ]
}
```

---

## 功能逻辑

### 导出
1. 点击"导出"按钮
2. 读取当前 `quickLinks` 数据
3. 生成带版本号的 JSON
4. 同时执行：
   - 创建临时 `<a>` 触发文件下载（`quick-links-backup.json`）
   - 复制 JSON 到剪贴板
5. 显示成功提示（"已导出并复制到剪贴板"）

### 导入
1. 点击"导入"按钮
2. 弹窗内显示两个选项：
   - 上传文件按钮（`<input type="file" accept=".json">`）
   - 文本框（粘贴 JSON）
3. 用户选择其一后验证格式
4. 若有效：替换 `quickLinks`，显示成功提示，关闭弹窗
5. 若无效：显示错误提示
