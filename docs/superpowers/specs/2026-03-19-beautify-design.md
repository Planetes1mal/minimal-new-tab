## 修复：快捷链接重复 Bug

### 问题
编辑已有快捷链接后，会出现两个一模一样的重复链接。

### 根因
`attachContextMenu` 函数（script.js:553）每次右键编辑时直接赋值 `saveLinkButton.onclick = updateHandler`，在快速操作时可能叠加执行，导致一次更新 + 一次新增。

### 修复方案
将保存按钮的 handler 改为单一函数，内部通过 modal 的状态标记判断是编辑还是新增模式。

```javascript
// 在 modal 上设置 data-mode 属性区分
modal.dataset.mode = 'edit'; // 或 'add'
```

## 美化设计

### 核心风格
- **柔和阴影**：多层阴影营造深度感
- **精致边框**：细边框（0.5-1px）+ 低对比度描边
- **微妙过渡**：hover 轻微放大 (scale 1.03-1.05)，0.2-0.3s 缓动

### 设计参考
Apple iOS/macOS 设计系统 — 极简毛玻璃 + 柔和光感

## 改动清单

### 1. 搜索框
| 状态 | 边框 | 阴影 | 其他 |
|------|------|------|------|
| 常规 | 0.5px, rgba 极低对比度 | 无 | backdrop-filter blur(20px) |
| 聚焦 | 1px, 边框颜色加深 | 添加柔和外发光 | scale(1.02), 背景更实 |

### 2. 快捷链接图标
| 状态 | 边框 | 阴影 | 其他 |
|------|------|------|------|
| 常规 | 0.5px | 0 2px 8px rgba(0,0,0,0.08), 0 4px 16px rgba(0,0,0,0.04) | - |
| Hover | 0.5px | 0 4px 12px rgba(0,0,0,0.12), 0 8px 24px rgba(0,0,0,0.08) | scale(1.05) |

### 3. 添加按钮
| 状态 | 边框 | 背景 |
|------|------|------|
| 常规 | 1px dashed, 40% 透明度 | 极淡灰 |
| Hover | 1px dashed, 80% 透明度 | 略深灰 |

### 4. 主题切换按钮
| 状态 | 边框 | 阴影 |
|------|------|------|
| 常规 | 0.5px | 0 2px 8px rgba(0,0,0,0.1) |
| Hover | 0.5px | 0 4px 16px rgba(0,0,0,0.15), scale(1.05) |

### 5. 弹窗
| 属性 | 值 |
|------|------|
| 圆角 | 24px（原 20px） |
| 阴影 | 0 8px 32px rgba(0,0,0,0.12), 0 2px 8px rgba(0,0,0,0.08) |

### 6. 过渡动画
- 默认时长: `0.25s cubic-bezier(0.25, 1, 0.5, 1)`
- Hover 放大: `scale(1.03)` 或 `scale(1.05)`
- 所有过渡使用统一的缓动曲线
